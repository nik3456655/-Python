Система управления кофейней на Python☕ Система управления кофейней на Python
Консольное приложение для управления заказами в кофейне. Программа демонстрирует применение базовых структур данных, управляющих конструкций и методов обработки данных в Python.
📋 Описание проекта
Pet-проект, созданный в процессе изучения Python. Реализует полный цикл работы с заказами: от просмотра меню до формирования чека и анализа статистики продаж.
🎯 Функционал
1. Просмотр меню кофейни
Вывод полного ассортимента в табличном формате
Нумерация позиций для удобства выбора
Отображение названия и цены каждого блюда
2. Создание нового заказа
Выбор позиций меню по номерам (через пробел)
Валидация введённых данных через try/except
Автоматический расчёт суммы заказа
Обработка некорректного ввода (буквы, несуществующие позиции, отрицательные числа)
Защита от пустого заказа
3. Расчёт стоимости и печать чека
Формирование детализированного чека с нумерацией
Итоговая сумма к оплате
Защита от повторного вывода одного чека (сброс флага после печати)
Автоматическое обнуление заказа после оформления
4. Статистика дня
Количество оформленных заказов
Максимальная сумма заказа (max())
Средний чек — математический расчёт (sum() / len())
Общая выручка за день (sum())
Защита от деления на ноль при отсутствии данных
5. Завершение работы
Корректное завершение программы через sys.exit()
🛠 Технологии и инструменты
Структуры данных
Кортежи (tuple) — хранение неизменяемого меню кофейни
python
  tuple_menu = (('Кофе', 160), ('Чай', 90), ('Сок', 100), ...)
  tuple_zakaz = ()  # Формируемый заказ
Списки (list) — динамическое хранение истории заказов
python
  histori_zakaz = []  # История сумм заказов
Управляющие конструкции
Цикл while True — главный цикл программы и цикл повторного ввода
Цикл for — итерация по элементам меню и заказа
Условные операторы if/elif/else — валидация и ветвление логики
match/case (Python 3.10+) — современная реализация меню выбора
Методы и функции
enumerate() — нумерация элементов с кастомным стартом
python
  for i, elem in enumerate(tuple_menu, start=1):
try/except ValueError — обработка некорректного пользовательского ввода
split() — разделение строки ввода на список позиций
map(int, ...) — преобразование строк в целые числа
append() — добавление элементов в список истории
sum(), max(), len() — математические операции со списками
sys.exit() — корректное завершение программы
Форматирование вывода
f-строки с выравниванием:
{текст:<30} — выравнивание влево (для названий)
{число:>10} — выравнивание вправо (для цен)
{число:^20} — выравнивание по центру (для заголовков)
{число:.2f} — форматирование чисел с 2 знаками после запятой
