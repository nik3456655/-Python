## 🎯 О проекте

**Система управления кофейней** — это консольное приложение, которое имитирует работу кассы в небольшой кофейне. Программа позволяет просматривать меню, создавать заказы, печатать чеки и анализировать статистику продаж за день.

> 💡 **Цель проекта:** закрепить знания базовых конструкций Python — циклов, условий, структур данных и обработки пользовательского ввода.

---

## ✨ Возможности

| № | Функция | Описание |
|---|---------|----------|
| 📋 | **Просмотр меню** | Красивая таблица с напитками и десертами |
| 🛒 | **Создание заказа** | Выбор позиций по номерам через пробел |
| 🧾 | **Печать чека** | Детализированный чек с итоговой суммой |
| 📊 | **Статистика дня** | Количество заказов, средний чек, выручка |
| 🚪 | **Завершение работы** | Корректный выход из программы |

### 🔐 Защита от ошибок

- ✅ Валидация пользовательского ввода (`try/except`)
- ✅ Проверка существующих позиций меню
- ✅ Защита от пустого заказа
- ✅ Защита от деления на ноль в статистике
- ✅ Защита от повторного вывода чека
